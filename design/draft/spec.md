## 2. 排版（4 级）

| 级别 | 大小 | 用在哪 | 字体 / 字重 / 行高 |
| --- | --- | --- | --- |
| display | `clamp(44px, 7.4vw, 72px)` | 只有页面主标题 | Newsreader 400 · 1.06 · `-.022em` |
| title | `clamp(24px, 2.6vw, 30px)` | 区块标题与卡片标题共用 | Newsreader 400 · 1.3 · `-.014em` |
| body | `18px` | 正文、说明、列表项、导航 | Inter 400（列表项 500）· 1.75 |
| meta | `14px` | 眉标、数字、页脚、药丸、箭头 | Inter 500 · 1.5 |

- 两种字体：Newsreader（衬线）+ Inter（无衬线）；`Noto Serif SC` 只是衬线的中文回退，不算第三款。
- 数字用 `font-variant-numeric: tabular-nums`，不引入等宽字体。
- 斜体用于强调（hero 的「慢慢写」）；中文为浏览器合成倾斜，按你的选择保留。

## 4. 组件

- **卡片**：内凹底色 + 1px 边框 + 10px 圆角 + 32px 内距；标题 title 级，下面一行 meta 级数字，底部箭头链接贴底。悬停 `translateY(-2px)` + 边框转淡赤陶。
- **药丸**：赤陶 tint 填充、无边框、14px/500。
- **列表**：每项上下各一条细线，相邻两项用 `-1px` 外边距叠成一条；行内只有「名字 + 一个 meta（分类或账号）+ 箭头」，箭头由伪元素生成，DOM 里不留多余节点。
- **箭头链接**：14px/500，下划线用 `text-decoration-color: transparent` 起步，悬停显色（可过渡，不闪）。
- **顶栏**：72px 高，1px 底线，半透明米白 + 轻微模糊；只有字标 + 3 个导航（文档 / 关于 / 联系），没有「外观」入口。

## 5. 动效

| 动效 | 参数 |
| --- | --- |
| 滚动淡入上移 | `opacity 0→1` + `translateY(12px→0)`，480ms `cubic-bezier(.2,.7,.3,1)`，同级每项 +70ms |
| 卡片悬停 | `translateY(-2px)`，200ms |
| 边框 / 文字变色 | 160ms |
| 减弱动效 | `prefers-reduced-motion: reduce`：淡入直接可见、卡片不位移、过渡全关 |

实测：首屏 3 项已显示，滚动后 13/13 全部触发；reduced-motion 下首屏内容直接可见（不会有「内容永远不出现」）。
