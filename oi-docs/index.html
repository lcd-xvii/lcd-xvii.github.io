使用帮助

OI 文档用于浏览题解、总结与算法理论资料。搜索支持多个关键词；结果按相关度排序，并可按标题或正文筛选。

快捷键

阅读与导航

  • 搜索：使用顶部主搜索筛选标题或正文；方向键选择结果，Enter 打开。
  • 目录：目录栏位于文档标题下方；点击目录栏标题可折叠条目，点击条目可跳转；按 Alt+m 展开目录。
  • 侧栏：点击顶部菜单按钮切换侧栏；拖动侧栏边缘调整宽度。按 Esc 也可关闭侧栏。
  • 复制：复制文档路径或代码块；标题旁的链条图标可打开对应标题锚点。
  • 外观：在设置中调整主题、字体、字号、每行文字宽度和代码换行。
