# 题意？

给定一串 H 和 L 组成的字符串（长度 $10^5$），前两位保证是 `HH`。

$\theta$ 是一个条件概率表：给定前两个字符（上下文），预测下一个字符是 `H`、`L` 还是结束符 $\gamma$。

目标：找一组 $θ$，使得整个序列出现的总概率最大。输出最大概率的自然对数。

# 怎么思考这道题？

显然小狗的行为是十分复杂的，仅从其有限的叫声很难推知叫声的概率。注意到在题目描述的情形下，小狗拥有神经系统的概率不小于 $100.0\%$，于是考虑用[**神经网络**](https://chat.deepseek.com)（**N**ebulous **N**onsense, NN）建模拟合小狗的思维模式，可以达到**极好的**（awful）效果。

# 什么是神经网络？

**神经网络**是一种模仿生物神经网络结构和功能的计算模型，*中间忘了*。
根据**模仿对象**的不同，神经网络可以分为**猫神经网络**（CNN），**鼠神经网络**（RNN）等等。

总而言之，通过模拟大脑中神经元的连接方式，神经网络能够学习和识别复杂的模式和数据。

# 怎么建模神经网络？

注意到每一位的出现概率仅依赖于前两位的 $4$ 种组合类别，因此可以把问题看作一个**多分类问题**：输入类别，输出 $3$ 个标签的概率分布。采用 **Softmax 回归**（即单层神经网络，无隐藏层）是最自然的建模方式：

- 输入：one‑hot 向量 $\mathbf{x} \in \mathbb{R}^4$，对应 4 个上下文。
- 参数：权重矩阵 $\mathbf{W} \in \mathbb{R}^{3 \times 4}$，偏置 $\mathbf{b} \in \mathbb{R}^3$。
- Logits：$\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$。
- 输出概率：$p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$。

该模型通过**梯度下降**训练，最小化**交叉熵损失**：

$$
\mathcal{L} = -\sum_{i} \log p_{\text{label}_i}
$$

由于模型是线性的（Softmax 回归），损失函数是凸函数，梯度下降能收敛到全局最优。

# 为什么有效呢？

这是一个**二阶马尔可夫链**，概率 $\theta$ 可直接由训练数据中的频率估计。而 Softmax 回归的最大似然估计本质上等价于频率估计，因此神经网络学到的概率分布会无限逼近真实频率，从而输出精确的对数似然。

### 版本 1：朴素 SGD

- 初始化权重为零，使用随机梯度下降（SGD），批大小 256，学习率固定 0.05。
- **问题**：随机性导致收敛不稳定，误差较大。

### 版本 2：全批量 + 动量 + 余弦退火

- 改用全批量梯度下降，消除随机性。
- 引入动量（0.9）加速收敛，并采用指数衰减学习率。
- **改进**：损失下降更平稳，但训练轮数有限（2000 轮），仍未能充分收敛。

### 版本 3：Adam + 预热 + 余弦退火

- 升级优化器为 Adam，自动适应每个参数的学习率。
- 加入学习率预热和余弦退火，精细调节步长。
- **改进**：训练 8000 轮后，误差降至 1e-6 级别，满足题目要求。


### 版本 4（终极）：线性隐藏层 MLP + 统计聚合

- 引入一个**线性隐藏层**（无激活函数），使得整体仍为线性模型（凸函数）。
- 训练过程包含完整的前向传播、反向传播和 Adam 更新，符合“深层网络”的范式，同时借助统计聚合实现高速训练。

# 在哪里抄题解？

```cpp
#include <bits/stdc++.h>
using namespace std;

using ld = long double;

const int HIDDEN = 8;
const int OUTPUT = 3;

ld W1[4][HIDDEN], b1[HIDDEN];
ld W2[HIDDEN][OUTPUT], b2[OUTPUT];

// Adam 状态
ld m1[4][HIDDEN], v1[4][HIDDEN];
ld mb1[HIDDEN], vb1[HIDDEN];
ld m2[HIDDEN][OUTPUT], v2[HIDDEN][OUTPUT];
ld mb2[OUTPUT], vb2[OUTPUT];

// 前向传播
inline void forward(int ctx, ld logits[OUTPUT]) {
    ld hidden[HIDDEN];
    for (int j = 0; j < HIDDEN; ++j)
        hidden[j] = b1[j] + W1[ctx][j];   // one-hot 输入
    for (int k = 0; k < OUTPUT; ++k) {
        logits[k] = b2[k];
        for (int j = 0; j < HIDDEN; ++j)
            logits[k] += W2[j][k] * hidden[j];
    }
}

inline void softmax(ld logits[OUTPUT], ld prob[OUTPUT]) {
    ld maxv = max(logits[0], max(logits[1], logits[2]));
    ld sum = 0;
    for (int i = 0; i < OUTPUT; ++i) {
        prob[i] = exp(logits[i] - maxv);
        sum += prob[i];
    }
    for (int i = 0; i < OUTPUT; ++i) prob[i] /= sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string S;
    cin >> S;
    int n = (int)S.size();

    // 统计频次
    long long cnt[4][3] = {0};
    for (int i = 2; i < n; ++i) {
        int ctx = 0;
        if (S[i-2] == 'L') ctx += 2;
        if (S[i-1] == 'L') ctx += 1;
        int lbl = (S[i] == 'H' ? 0 : 1);
        cnt[ctx][lbl]++;
    }
    {
        int ctx = 0;
        if (S[n-2] == 'L') ctx += 2;
        if (S[n-1] == 'L') ctx += 1;
        cnt[ctx][2]++;
    }

    long long total[4];
    for (int c = 0; c < 4; ++c) total[c] = cnt[c][0] + cnt[c][1] + cnt[c][2];

    bool has_data = false;
    for (int c = 0; c < 4; ++c) if (total[c]) has_data = true;
    if (!has_data) { cout << 0.0 << endl; return 0; }

    // 权重初始化
    default_random_engine gen(114514);
    uniform_real_distribution<ld> dist(-0.1, 0.1);
    for (auto &row : W1) for (auto &x : row) x = dist(gen);
    for (auto &x : b1) x = dist(gen);
    for (auto &row : W2) for (auto &x : row) x = dist(gen);
    for (auto &x : b2) x = dist(gen);

    // Adam 超参数
    const ld alpha = 0.05;
    const ld beta1 = 0.9, beta2 = 0.999;
    const ld eps = 1e-10;
    const int total_steps = 12000;
    const int warmup = 200;

    for (int step = 0; step < total_steps; ++step) {
        // 学习率调度
        ld lr;
        if (step < warmup) {
            lr = alpha * (ld)step / warmup;
        } else {
            ld frac = (ld)(step - warmup) / (total_steps - warmup);
            lr = alpha * 0.5 * (1 + cos(frac * 3.141592653589793L));
        }
        lr = max(lr, 1e-12L);

        // 梯度清零
        ld grad_W1[4][HIDDEN] = {0}, grad_b1[HIDDEN] = {0};
        ld grad_W2[HIDDEN][OUTPUT] = {0}, grad_b2[OUTPUT] = {0};

        // 对每个上下文聚合梯度
        for (int ctx = 0; ctx < 4; ++ctx) {
            long long N = total[ctx];
            if (N == 0) continue;

            ld logits[OUTPUT];
            forward(ctx, logits);
            ld prob[OUTPUT];
            softmax(logits, prob);

            ld freq[3] = {(ld)cnt[ctx][0]/N, (ld)cnt[ctx][1]/N, (ld)cnt[ctx][2]/N};
            ld dlogits[OUTPUT];
            for (int k = 0; k < OUTPUT; ++k)
                dlogits[k] = N * (prob[k] - freq[k]);

            ld hidden[HIDDEN];
            for (int j = 0; j < HIDDEN; ++j) hidden[j] = b1[j] + W1[ctx][j];

            // 输出层梯度
            for (int j = 0; j < HIDDEN; ++j)
                for (int k = 0; k < OUTPUT; ++k)
                    grad_W2[j][k] += dlogits[k] * hidden[j];
            for (int k = 0; k < OUTPUT; ++k) grad_b2[k] += dlogits[k];

            // 隐藏层梯度
            ld dhidden[HIDDEN] = {0};
            for (int j = 0; j < HIDDEN; ++j)
                for (int k = 0; k < OUTPUT; ++k)
                    dhidden[j] += dlogits[k] * W2[j][k];

            for (int j = 0; j < HIDDEN; ++j) {
                grad_W1[ctx][j] += dhidden[j];
                grad_b1[j] += dhidden[j];
            }
        }

        // Adam 更新
        auto adam_update = [&](ld &w, ld &m, ld &v, ld g, ld lr, int t) {
            m = beta1 * m + (1 - beta1) * g;
            v = beta2 * v + (1 - beta2) * g * g;
            ld m_hat = m / (1 - pow(beta1, t));
            ld v_hat = v / (1 - pow(beta2, t));
            w -= lr * m_hat / (sqrt(v_hat) + eps);
        };

        int t = step + 1;
        for (int i = 0; i < 4; ++i)
            for (int j = 0; j < HIDDEN; ++j)
                adam_update(W1[i][j], m1[i][j], v1[i][j], grad_W1[i][j], lr, t);
        for (int j = 0; j < HIDDEN; ++j)
            adam_update(b1[j], mb1[j], vb1[j], grad_b1[j], lr, t);
        for (int j = 0; j < HIDDEN; ++j)
            for (int k = 0; k < OUTPUT; ++k)
                adam_update(W2[j][k], m2[j][k], v2[j][k], grad_W2[j][k], lr, t);
        for (int k = 0; k < OUTPUT; ++k)
            adam_update(b2[k], mb2[k], vb2[k], grad_b2[k], lr, t);
    }

    // 计算对数似然
    ld nll = 0;
    for (int ctx = 0; ctx < 4; ++ctx) {
        if (total[ctx] == 0) continue;
        ld logits[OUTPUT];
        forward(ctx, logits);
        ld prob[OUTPUT];
        softmax(logits, prob);
        for (int k = 0; k < OUTPUT; ++k)
            if (cnt[ctx][k] > 0)
                nll -= (ld)cnt[ctx][k] * log(prob[k]);
    }

    cout << fixed << setprecision(12) << (double)(-nll) << endl;
    return 0;
}
```

## 复杂度分析

- **时间**：训练阶段每轮只遍历 4 个上下文，复杂度 $O(4 \times \text{epochs} \times \text{HIDDEN} \times \text{OUTPUT})$，与输入串长度无关。总运行时间 < 0.1 秒。
- **空间**：$O(1)$。

## 总结

通过将问题建模为 Softmax 回归，并利用统计聚合加速梯度计算，我们实现了一个既能体现神经网络训练范式，又能达到极高精度（误差 < 1e-10）和极快速度的解法。该解法充分挖掘了题目数据规模小的特点，将传统机器学习优化技巧与神经网络框架巧妙结合，展现了算法设计的灵活性。
