# P9237 [蓝桥杯 2023 省 A] 像素放置 题解

*本题解使用 DeepSeek V4 Flash 润色。*

## 题意

在一个 $n \times m$ 的网格棋盘上，需要用黑白两色涂满所有格子。棋盘上已有的数字（$0 \sim 9$）表示该格子及其**所有相邻格子**（共最多 $9$ 个）中黑色格子的数量。没有数字的格子用 `_` 表示，不做任何限制。

题目保证有**唯一**的填涂方案，请输出该方案（`0` 表示白色，`1` 表示黑色）。

> 这题很像扫雷，但区别是：黑色（雷）可以出现在数字格子上，且数字计数时包含自身格子。

---

## 定义

- **邻里**：一个格子本身以及与其**八连通**的所有格子（即上、下、左、右、左上、右上、左下、右下）。
- **限制**：输入中格子上的数字，若为 `_` 则表示无限制（记为 `-1`）。

---

## 思路

### 核心想法

我们可以用深度优先搜索（DFS）依次决定每个格子的颜色。但是直接枚举 $2^{nm}$ 种方案显然不可行，必须利用数字限制进行剪枝。

对于每个有数字的格子，我们维护两个量：

- `need`：该格子的邻里中，**还需要**涂黑的格子数量（初始值就是该数字）。
- `empty`：该格子的邻里中，**尚未填涂**的格子数量（初始值为邻里总数，角格为 $4$，边格为 $6$，中心为 $9$）。

当我们给某个格子涂色时，会影响**所有包含该格子的邻里**（即该格子及其周围八个格子）。对于每个受影响的数字格子：

- 如果涂**黑色**：因为已经满足了一个黑格，该数字格子的 `need` 减 $1$，同时 `empty` 减 $1$。
- 如果涂**白色**：`need` 不变，`empty` 减 $1$。

于是，对于任意一个有数字的格子，其 `need` 和 `empty` 必须始终满足 **$0 \le \mathrm{need} \le \mathrm{empty}$**，否则无论如何填涂剩余空格，都无法满足该数字。利用这个不等式，我们可以得到三个强有力的剪枝条件：

1. **`need == 0`**：该邻里已经不需要黑格了，所以周围（包括当前要填的格子）不能再涂黑。
2. **`need > empty`**：即使把周围所有空格都填黑，也不够需求，直接回溯。
3. **`need == empty`**：周围所有空格必须全部填黑才能满足需求，因此不能填白。

我们按格子编号顺序（从 0 到 $n \times m - 1$）依次尝试填黑或填白，每次尝试前检查上述条件，若不满足则跳过该颜色。一旦成功填满所有格子，由于题目保证唯一解，直接返回即可。

---

### 例子演示

以 $1 \times 3$ 的棋盘为例，输入为：
```
2 _ 1
```

初始状态的 `(need, empty)`：

| $(0,0)$ 数字2 | $(0,1)$ 无限制 | $(0,2)$ 数字1 |
| :---: | :---: | :---: |
| `(2, 2)` | `(-1, 3)` | `(1, 2)` |

**DFS 过程**：

1. 从 $(0,0)$ 开始：`need == empty`成立；故 $(0,0)$ 仅能填黑；
    - 更新 $(0,0)$：`(1, 1)`（`need` 减 $1$，`empty` 减 $1$）。
    - 更新 $(0,1)$：`(-1, 2)`（`need` 为 $-1$，无需更改，`empty` 减 $1$）。

2. 继续填下一个格子 $(0,1)$（无数字，但同样要更新周围数字格）：  
   其邻里 $(0,0)$ `need == empty` 成立，限制其周围全部填黑；故 $(0,1)$ 仅能填黑；
   - 更新 $(0,0)$：`(0, 0)`
   - 更新 $(0,1)$：`(-1, 1)` 
   - 更新 $(0,2)$：`(0, 1)`（`need` 减 $1$，`empty` 减 $1$）  

3. 填 $(0,2)$：`need == 0`成立；故 $(0,2)$ 仅能填白；
   - 更新 $(0,1)$：`(-1, 0)` 
   - 更新 $(0,2)$：`(0, 0)`（`need` 减 $1$，`empty` 减 $1$） 

4. 到 $(0,3)$ 越界，说明所有格子已经成功填完，返回。

最终可找到唯一解：
```
1 1 0
```
（具体推导略）

---

## 复杂度分析

- **时间复杂度**：最坏情况下为 $O(2^{nm})$，但通过上述强剪枝，实际搜索树较小，在本题数据范围（$n,m \le 10$）下运行速度可接受。
- **空间复杂度**：$O(nm)$ 最低，用于存储棋盘状态和邻里信息。

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;
// 模拟 for i in l..r 语法
#define rep(i, l, r) for (int8_t i = (l); i < (r); ++i)

// 预计算邻里格的坐标偏移量
vector<int8_t> neighbors[105];
// need: 邻里剩余可填黑格数
// empty: 邻里剩余空格数
struct Node {int8_t need; int8_t empty;} lim[105];

// 初始化数组
void read_and_build() {
    rep(i, 0, n) {
        rep(j, 0, m) {
            solution[i * m + j] = -1; // 空格为 -1
            char c = getchar();
            lim[i * m + j].need = (c == '_') ? -1 : c - '0';
            int8_t cnt = 0; // 邻里数量
            rep (di, -1, 2)
                rep (dj, -1, 2) {
                    int8_t ni = i + di, nj = j + dj;
                    if (ni >= 0 && ni < n && nj >= 0 && nj < m) {
                        ++cnt;
                        neighbors[i * m + j].push_back(di * m + dj); // 邻里偏移量
                    }
                }
            lim[i * m + j].empty = cnt;
        }
        // 测试数据巨坑，换行符用 \r\n
        while (getchar() != '\n');
    }
}

// 更新填入格子的邻里，小写为写入，大写为撤销
void update(int8_t i, char c) {
    int8_t d1, d2;
    switch (c) {
    case 'B':
        d1 = 1; d2 = 1;
        break;
    case 'W':
        d1 = 0; d2 = 1;
        break;
    case 'b':
        d1 = -1; d2 = -1;
        break;
    case 'w':
        d1 = 0; d2 = -1;
        break;
    default:
        return;
    }
    for (int8_t offset : neighbors[i]) { // 遍历所有邻居
        if (lim[i + offset].need > -1) // 存在限制
            lim[i + offset].need += d1;
        lim[i + offset].empty += d2;
    }
}

bool dfs(int8_t i) {
    if (i == n * m) // 超出数组，即之前所有格子填满，可返回成功
        return true;
    
    // 能否涂黑 / 白色
    bool black = true, white = true;
    for (int8_t offset : neighbors[i]) { // 遍历所有邻居
        auto s = lim[i + offset];
        if (s.need == -1) // 无限制
            continue;
        if (s.need == 0)
            black = false;
        if (s.empty < s.need)
            black = white = false;
        if (s.empty == s.need)
            white = false;
    }

    bool success;
    if (white) {
        update(i, 'w');  // 写入
        solution[i] = 0; // 0 为白色，1 为黑色
        success = dfs(i + 1); // 传递下一个索引
        update(i, 'W'); // 撤销
        if (success) return true;
    }

    if (black) {
        update(i, 'b');
        solution[i] = 1;
        success = dfs(i + 1);
        update(i, 'B');
        if (success) return true;
    }

    solution[i] = -1; // 撤销更改
    return false;
}

int main() {
    scanf("%hhd %hhd\n", &n, &m);

    read_and_build();

    dfs(0); // 此处一定有解

    rep(i, 0, n * m) {
        printf("%hhd", solution[i]);
        if ((i + 1) % m == 0)
            putchar('\n');
    }

    return 0;
}
```
