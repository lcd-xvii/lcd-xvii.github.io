# 0927 周总结

## 0923 考试分析

### T1

**题意**：吃豆人，所有人向剩余最大豆子移动，求每颗豆子的食用者。

数据结构典题，可惜我看到线段树还是畏惧了，决定用树状数组但没调过。树状数组解法是维护人的位置差分，把区间修改+单点查询变为单点修改+区间查询。这是对的，但是同时到的人小编号的吃掉，而初始又无序，注意到相对位置不变，需要用 ST 表维护区间最小。另一个神秘优化是**树状数组倍增**，利用 ST 表的思想和树状数组维护 $2^i$ 的性质，可以在 $O(\log n)$ 复杂度内完成树状数组的前缀和插入位置查询，比二分版本少一个 $\log$，思想是很妙的。

**总结**：不要害怕数据结构题目，只要去调都有转机的；同时应加强基础数据结构练习，避免因为数据结构而浪费思考时间。

### T2

**题意**：连通图找路径，使得分割两个子图且子图大小相等。

很好的题目，Adhoc。正解是深搜，一开始全放 A 集合，搜进时从 A 移入 P，回溯时从 P 移入 B。显然总会 $#A=#B$。这个 DFS 性质的运用可谓绝妙，果然 Adhoc 题有助于提升思维。

## 0924 考试分析

### T1

**题意**：给序列，可以沿一个高度将其左/右的所有反转，最后要都正且严格单增，求序列末项的最小值。

被绿题卡了。显然差分后面的都不变，只要首项最小即可。注意到首项的变化其实是加减后面差分的带符号前缀和，我想到背包去了，实际上因为可以无限加减，所以就是裴蜀定理的一般结论，`gcd` 就秒了。

**总结**：看到简单题要达到无调试一遍过，才能为难题留下时间；难题在知识点覆盖全前尝试应用已有的知识拿次优/部分分，系统性学完后应可以识别题目核心算法。

### T2

**题意**：排列给定序列并附上正负号，使得其前缀和符合给定的符号序列。

构造题，而且思路依旧神奇。块边界优先，因为需要的权重大。如果前大后小那多半扳不回来，所以前小后大，这没有问题。但是下一步就很神奇：剩下的从前往后从大到小排，相邻交替符号，已放的边界不算。因为递减保证了上界减而下界增，也就是一定能被下一个更大的边界扳回；而交替正负号意味着此处的上意味着前处的下，可以抵消成无影响，**妙啊**。去除边界看，就是往中心收敛；而边界总是够大来改变整体上下，非常巧妙。

### T3

**题意**：优化 DP 转移 $dp_i=\min_{1\le j< i}\{dp_j+\min(a_j,\cdots,a_i)\times(i-j)^2\}$。

这题也很好。我在 @lwh 的补题记录上看见了绝妙解法。

一个性质是只有在最小值端点处转移才最优，另一个是跳了超过 $\fact{n}{a_i}$ 步肯定亏。正常做法到这里就分讨了，但是这个解法**直接认定 $a_i$ 是区间最小值**，然后往两端扩展并更新右端点，小于和等于都可以剪掉。最妙的在于一般 DP 都是顺序推，而这个竟然在前面就开始更新后面了，确实超出常规。

**总结**：Adhoc 可以提升思维，但是一场考试 3 个 Adhoc 还是算了。

## 0926 考试分析

### T1

**题意**：排列使得前缀 $\max-\min$ 之和固定。

构造题，贪心即可。第二种可以互换数 $1,2$ 得到。

### T3

**题意**：构造 $0\sim n-1$ 的两个排列，使得其异或也是一个排列。

我终于弄懂了这道题。思路：

1、观察发现 $n=1$ 或 $n\%4=0$ 有解。

2、令 $m=n/4$，构造一组长为 $m$ **双排列** $a,b$，他们可以利用 $4$ 的解去推原答案。

3、对于 $n=2^i$，我们有神秘 $i$ 异或 $\lfloor i\rlfoor$ 来构造 $a,b$。

4、对于其他，我们将其拆位，递归求解，同时满足一个前缀限制。

5、通过玄学拼装，组成答案。

**总结**：多锻炼思维，可以在考场上构造出非正常想法的解。
