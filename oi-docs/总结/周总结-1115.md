### recall
**题意**：构造 $1\sim n$ 排列，使得 $p_i\oplus p_{i+1}>|p_i-p_{i+1}|$。

**解法**：周知异或是无进位加法，而比较不那么广为人知的是，异或也是**无退位减法**。
> 二进制下，一位加、减、异或 $0$ 都不变，加、减、异或 $1$ 都翻转。

既然是严格大于，也就是说减法必须退位，那么 $p_i$ 和 $p_{i+1}$ 为 $1$ 的位一定不能有包含关系。
形式化的，$p_i\&p_{i+1}\ne\min(p_i,p_{i+1})$。

你需要性质。
如果一个小奇数和一个大偶数相邻，奇数的最低位多一个 $1$，并肯定在某个高位置少一个 $1$，于是就合法。

自然，若 $n$ 为偶数，有形如 $2,1,4,3,...,n,n-1$ 的构造。

那若 $n$ 为奇数？
你会想把它放在 $2$ 前面或 $p_{n-i}=n-2$ 后面。
发现合法条件都是 $n\&2=0$，也比较显然。

那么最后就是 $n\&3=3$ 了，此时对 $2$ 包含，对 $n-2$ 无退位。
那我想在 $n-2$ 和 $n$ 中间插一个数，这个数只要在 $n$ 为 $0$ 的位上为 $1$ 就没什么问题了。

又能发现，一个偶数 $p_i$ 的两边必然是 $p_{i-1}=p_i-3$ 和 $p_{i+1}=p_i-1$，你要把 $p_i$ 拿走，那你大概能确定一种，比如说 $p_i-1=10...01_2$，而 $p_i-3=01...11_2$，就没什么问题。

也就是，你取走一个 $10...010_2$ 的偶数，左右两边满足，而其最高位的 $1$ 是 $n$ 最低的 $0$ 就行了。

代码简短：
```cpp
int t; read(t);
while (t--) {
    int n; read(n);
    if (n == 1) put("1");
    else if (!(n & (n + 1))) put("-1");
    else {
        int x = (n & 3) == 3 ? x = ~n & (n + 1) | 2 : 0;
        // 2 1 4 3 6 5 ...
        rep(i, 2, n + 1, 2) {
            if (i != x) write(i), pc(' ');
            write(i - 1), pc(' ');
        }
        if (n & 1) {
            if (x) write(x), pc(' ');
            write(n), pc(' ');
        }
    }
    pc('\n');
}
```

> 位运算我似乎找到了一些技巧，现在可以算擅长了。
> 归功于 P14025 和 QOJ12004 两道。

### rakishu
**题意**：A 类点无限制，B/C 类点度数最多 $1$，C 类还限制其相邻点度数为 $1$。求边数最大。

**解法**：这道题很没意思。
而且为什么会有“shu”这么奇怪的发音，文件名差点打错？

你会想 C 之间两两配对，A 连成一个完全图，然后在加上每个 $B$ 多一条边，答案是 $a(a-1)/2+\lfloor c/2\rfloor+b$。

如果没有 $a$，$b$ 也变成 $\lfloor b/2\rfloor$。
这时要是 $c\equiv b\equiv 1\pmod2$，可以多 $1$。
然而又有神秘 corner case，就是如果 $(a,b,c)=(1,0,2k+1)$，出了个 $C\leftrightarrow A$ 边。
> **考场上如何找完 corner？**
>
> 出现向下取整时注意，这里可能会出一个孤点。
> 因此可能有 $1$ 个孤 B，$1$ 个孤 C。
>
> 然后一定列出来：
> |#|孤 B|A|
> |-|-|-|
> |孤 C|`b & c & 1`|`!b && a==1 && (c & 1)`|
> |A|`0`（有 A 则无孤 B）|-|
>
> 这样大概就不会错了。

极简代码：
```cpp
ll a, b, c; read(a, b, c);
write(
    a * (a - 1) / 2
    + (a ? b : b / 2 + (c & b & 1))
    + c / 2
    + (!b && a == 1 && (c & 1))
); pc('\n');
```

### koron
**题意**：给 $1\sim n$ 排列 $p$，你可以选 $i<j<k$，若 $p_i>p_k$，交换 $p_i,p_j$；否则交换 $p_j,p_k$。
$n+1$ 步之内要变升序。

**解法**：这种构造题还是比较靠练习。
没想到假算这么多，变成唯一 A 的了。

首先 $1$ 在最右不行，一些小数据不行/特殊。

xxs 都能发现要把 $1$ 移到 $p_1$，然后后面操作至多 $n-2$ 次（注意 $n$ 自动归位）$(1,p_i,pos_i)$。
也就是，$1$ 归位给了你 $3$ 步。

这道题倒推是一个很棒的思路。
- 要把 $1$ 挪到最左，显然它是作为中间的数，那么 $p_1$ 要大于 $1$ 右边某个数；我要保证有，就把 $n$ 挪到最左；
- 要把 $n$ 挪到最左，同理，$p_1$ 要大于 $n$ 右边某个数；这时保证不了 $p_1$ 了，但是你可以保证右边有 $1$；即把 $n$ 移到 $1$ 左边；
- 要把 $n$ 移到 $1$ 左边，这个简单完了，只要做 $(1,pos_1,pos_n)$ 就可以，但是 $1$ 可能换到最右边，所以 $n$ 要脱离 $p_n$；
- $n$ 要脱离 $p_n$，显然随便就好。

不好，用了 $4$ 步！

仔细分析。
$4$ 步意味着什么？
- $p_n=n$；
- $pos_1=2$：因为否则你可以在 $n$ 在最右操作 $(1,2,n)$，直接到 $1$ 左侧去了；只有 $1$ 本身很靠左才不能这样。

怎么办？
分析 $p_1$：它会在 $n$ 置换的那一步被移出，因为 $n$ 会先到 $1$ 的位置也就是 $p_2$，所以 $p_1$ 最终在 $p_2$。

如果 $p_1=2$，$2$ 也被归位了，后面省了一步，这里多的一步抵消了。

否则，你可以开局就 $(1,2,pos_2)$ 这种，把 $1$ 归位。

由上就完成了，代码：
```cpp
int n, k; read(n, k);
for (int i : range(1, n + 1)) read(p[i]), pos[p[i]] = i;

if (n == 1) return write("Daisuki\n0\n"), 0;
if (n == 3 && p[1] == 3 && p[2] == 1 && p[3] == 2)
    return write("Daisuki\n2\n1 2 3\n1 2 3\n"), 0;
if (n == 2 && p[1] != 1
    || n == 3 && p[1] != 1
    || pos[1] == n)
    return write("Kawaii\n"), 0;
write("Daisuki\n");

vector<tuple<int, int, int>> op;
auto do_left = [&](int i, int j, int k) {
    op.emplace_back(i, j, k);
    swap(pos[p[i]], pos[p[j]]);
    swap(p[i], p[j]);
};
auto do_right = [&](int i, int j, int k) {
    op.emplace_back(i, j, k);
    swap(pos[p[j]], pos[p[k]]);
    swap(p[j], p[k]);
};
if (pos[1] != 1) [&]() {
    // 最后 3 分钟写出的：
    for (int i : range(pos[1] + 1, n + 1))
        if (p[i] < p[1])
            return do_left(1, pos[1], i);
    // 1. 把 n 移到 1 左边
    if (pos[n] > pos[1]) {
        if (pos[1] == 2 && pos[n] == n)
            do_right(pos[1], pos[1]+1, pos[n]);  // n 向左
        if (pos[1] != 2)
            do_right(1, pos[1]-1, pos[n]);
        else do_right(1, pos[1], pos[n]);
    }
    // 2. n -> pos[1]
    if (pos[n] > 1) do_left(1, pos[n], pos[1]);
    // 3. 1 -> pos[1]
    do_left(1, pos[1], pos[1] + 1);
}();

for (int i : range(2, n + 1))
    if (pos[i] != i) do_right(1, i, pos[i]);
write(op.size()); pc('\n');
for (auto tp : op)
    write(get<0>(tp), get<1>(tp), get<2>(tp)), pc('\n');
```
