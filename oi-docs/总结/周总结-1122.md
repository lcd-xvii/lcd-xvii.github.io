## 考试情况

### lead

**题意**：每次 $n$ 名玩家选择 $0/1$，与答案相同加 $1$ 分，否则不变。
$1$ 号玩家始终选其余分数最高玩家中出现最多的答案，如果人数相同即随机选。
给定每个人的初始分数，求 $1$ 号玩家的分数至少能保持几个回合不被超越。

**解法**：考场上卡了很不少时间，最后因为 `long long` 挂分。

其实就是让你构造方案，使 $1$ 号运气最差。
我们观察到，如果有一轮 $1$ 号玩家得分了，那这对后面玩家追赶他是无效回合，所以 $1$ 号永远不得分。

又因为 $1$ 号只看最高分的人，那么就让所有不是最高的玩家和最高分玩家的 $1/2$（下取整）得分，最坏情况下 $1$ 号不得分。
这意味着，每次最高分玩家的数量会折半，于是经历 $\lg$ 轮。

对于某位最开始的最高分玩家，总是会在某一轮不让加。
这是好办的，由于他从此不是最高，后面所有轮都可以加，也就是只与最高分差距为 $1$。

> 特别地，最后留下的 $1$ 位最高分玩家在最后一轮不能加，所以也是少 $1$ 轮。

总之，最高分每 $\lg+1$ 轮增加 $\lg$。
并且，最高分的玩家集合不会缩小。

那会不会增大？你会发现，开始的时候不是最高分，比最高分多进化 $1$ 轮，即每个循环差距减 $1$。
那就开始时从大到小排序，$O(1)$ 计算每一名玩家加入最大值队伍的时间就行了。
如果途中已经超越玩家 $1$ 了，直接 `break` 掉。

### pattern

**题意**：给 $A/B$ 两个 $0/1$ 图案和它们按像素异或后的图案 $C$，求异或时的对齐偏移量。

**解法**：有点诈骗。

1. 一个 $1$ 一定来自一个 $1$ 异或上一个 $0$；
2. 异或是可逆的。

虽然是显而易见的结论，但是暗示我们从特定像素点入手。

定义“代表点”为一张图案的左上角第一个 $1$ 像素点。

假设 $A/B$ 的代表点重合了，那么 $C$ 的代表点一定在对齐点的右方或下方。

如果未重合，不难发现，$C$ 的代表点必然是 $A$ 和 $B$ 的代表点中的一个——因为 $A/B$ 的代表点中必然有一个在另一个的左方或上方，那它的左上象限是没有其他点的；$C$ 的代表点即是由它异或上 $0$ 产生的。
> 如果对应位置是异或 $1$，那么读者不妨自证，另一个代表点就满足条件。

于是就极其简单：枚举图片对并一一对齐左上角、异或，与剩下的对比即可。
这里可以贺 `checker.cpp`。

### light

**题意**：求 $1\sim n$ 排列数量，约束排列中数字 $i$ 两侧比它小的数字数量不小于 $a_i\in\{0,1,2\}$。

**解法**：连续段 DP 是蓝ですか。

连续段 DP 的一般形式为 $dp_{i,j}$，表示到前 $i$ 个数，已经分了 $j$ 个连续段。

一个段的意思是，段内部满足题目要求，但是段间是无约束的。
由于最终求单独的序列，所以终止时段数应为 $1$。

这道题中，我们可以用经典的手段，从小到大插入数。
转移分 $3$ 种：

1. **连接段**：因为插入的位置一定两边更小，所以 $\{0,1,2\}$ 都合法，但只能插中间的空。
即 $dp_{i,j}\gets j\cdot dp_{i-1,j+1}$；
2. **扩充段**：这里扩充的一端是小的，等待粘合的一端是大的，因此 $\{0,1\}$ 可以。
注意扩充分左右，于是 $dp_{i,j}\gets 2j\cdot dp_{i-1,j}$；
3. **新增段**：未来一定是由更大的数连接起来的，所以需求为 $0$ 才合法，两边也可以插入，有 $dp_{i,j}\gets j\cdot dp_{i-1,j-1}$。

实在是妙妙 trick。

### cerydra

**题意**：（改的洛谷题面，描述比较清楚）

有一个长为 $n$ 的排列 $p$。
对每个 $i\in[1,n]$，统计满足下述条件的区间 $(l,r)$ 的数量：
$1\le l\le r\le n$，且子数组 $p_l,p_{l+1},\dots,p_r$ 的最小值恰好等于 $p_i$，记作 $a_i$。

现已知 $a_1,a_2,\dots,a_n$，求合法 $p$ 的种数。

**解法**：听说名为最值分治，但是没有看出什么特别的思想。

对于一个区间，注意到区间最小值在所有包含它的子区间中都被计数，根据其相对位置，答案为 $(i+1)(r-l+1-i)$。

由于肯定只有一个区间最小，因此遍历区间去扫描该最小值，然后**所有跨过最小值的区间都不可能是其他位置的贡献**了，于是沿最小值切成两半，即分治。

你会发现线性扫是最坏 $O(n)$ 的，然而有个性质是扫的远必然对应区间长；亦即，如果平衡区间长度及扫描时间的话，用双指针就可以了。

> **时间复杂度证明**
>
> 每次扫描，复杂度是 $O(\min(i-l,r-i))$ 左右的。
> 也就是说，复杂度可以视作摊给划分后短区间的每个元素 $1$ 个单位。
>
> 非常好的是，一个元素最多被分配 $\log_2$ 个单位。
> 这是因为它每次计费时都在短区间里，于是每个计费都会导致其所在区间长度至少减半。
> 由上得证 $O(n\log n)$。

分治出答案了，合并时，重点是只要**最小值相对位置不变**就行了，左右区间内的排列方案，都不影响最小值答案的合法性。

于是可以随意分配数，答案是 $\operatorname{solve}(l,i-1)\times \operatorname{solve}(i+1,r)\times{r-l\choose i-l}$。

唯一需要判断的边界是，到叶子时如果不是 $1$ 就无解；其他边界会被分治自动处理掉。

### mushroom

**题意**：给定序列，已经固定一些位置和值，有一些值要你填进位置，使得操作结束后，剩下的数最大。

操作方法：取队列前 $3$ 个数，丢弃最大最小，中位数塞回队尾。

**解法**：我觉得题出的还不错。
重点是要看出二分答案。

二分，对于每个值，大于等于当前答案为 $1$，否则为 $0$。

为了结果大，我们肯定希望留下来的是 $1$，也就是取出时至少 $2$ 个 $1$。

有些数不确定，我们不妨给每个数为 $1$ 设一个代价，表示为了此处为 $1$ 需要消耗的 $1$ 数量。

对于已经确定好的位置，满足者初始代价为 $0$，否则为 $+\infty$。
不确定的，都把代价初始设成 $1$。

然后你去模拟转移。
首先初始代价全部进队。
你从前部弹出 $3$ 个代价，因为至少 $2$ 个 $1$，所以塞入队尾的代价是 $3$ 中选 $2$ 个代价最小的之和。

最后模拟完留下的代价，与实际待放置值的 $1$ 的数量比较，决定二分方向。

> 语言描述很不严谨，AI 形式化后是这样：
> ```
> 二分答案 mid
>
> 对于每个位置 i：
>   - 如果已固定且 a[i] ≥ mid: 代价 = 0（已经是1）
>   - 如果已固定且 a[i] < mid:  代价 = +∞（无法改变，永远是0）
>   - 如果未固定:               代价 = 1（可以放一个≥mid的值）
>
> 统计：available_ones = |{v ∈ fill_values : v ≥ mid}|
>       （有多少个待填值可以变成1）
>
> 模拟队列操作，得到最终代价 final_cost
>
> 判断：final_cost ≤ available_ones ?
> ```

### P1

**题意**：给你 $0/1$ 串，每次操作将一个 $1$ 边上的 $0$ 传染成 $1$，求序列回文的最小操作次数。

**解法**：大概有更好理解的思路吧。

从中间向外 DP，记录最小次数。
显然每层 DP 的 $2$ 个数是相同的，分别有 `dp0[N]` 和 `dp1[N][2][2]`。
`dp1` 的后两个维度表示左边/右边的 $1$ 是否依赖外层（未转移到的）传过来。

对于 `dp0` 的转移：

第 $i$ 层可以为 $0$，说明不需要染色这层以传播 $1$，那么 $i-1$ 层一定要是从中间变成 $1$ 的（不依赖外部染色源），或者本来也是 $0$。
转移方程为 $dp0_i\gets\min(dp0_{i-1},dp1_{i-1,1,1})$，注意由于 $1$ 不能变 $0$，这层 $2$ 个得本来是 $0$ 才行，不然为 $+\infty$。

对于 `dp1` 的转移：

假设这层两个数本来是 $x,y$。

$dp1_{i,x,y}\gets dp0_{i-1}$，表示如果内层不能传来的话，自身本来的值决定是否依赖外层。

然后遍历 $a\in\{0,1\},b\in\{0,1\}$，有

$$
dp1_{i,a|x,b|y}\gets min(\dots,dp1_{i-1,a,b})
$$

说到底就是本来是 $1$ 的无论如何不会依赖外层；本来是 $0$ 的，如果内层也在依赖外层，它就得将依赖传下去；否则可以自足。

结束时要么两端是一对 $0$，要么是不依赖更外层的一对 $1$，总之答案有 $\min(dp0_{\lceil n/2\rceil},dp1_{\lceil n/2\rceil,1,1})$。
