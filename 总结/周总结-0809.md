# 学习情况

## 周一：状压 DP 

状压 DP 和普通 DP 的应用场景不一样：单个状态维数小，还要有多个并列的分量，分量的种数要有限；状态总数多，每次需要对多个分量同时处理。

位运算高效地编码状态，不仅提高效率，而且节约写修改多个分量的方法的时间。

状压的代码量还算比较少，题目也比较好分辨，但在解题过程中找到转移方程并合理使用位运算是关键。

下午的轮廓线 DP 是状压的精华，通过及时舍弃不影响结果的数据把 $ O(n^2)$ 的空间复杂度开根，尤其适用于二维网格类问题。


## 周二：数位 DP 和单调队列优化 DP 

数位 DP 非常明显，重点依旧是转移方程。

数位 DP 因为要考虑每一位，所以一般只能出区间类限制，只要区分好位是否受上限限制即可，下线往往做差消去。

如果用记忆化搜索，主逻辑就是从高往低的 DFS ，更加清晰简洁，比较好写。
单调队列优化 DP 个人觉得比较难，因为是常见的代价类不好区分，又比较迷惑，找不出最值与单调队列的关系。

不过似乎依赖主流 DP 思想，再手画前几个情况，一般都可以有思路（或复杂度不太好的解法）。


## 周三：斜率优化 DP 

初看觉得非常难——要从一个带最值、偏移、平方的式子里发现与斜率公式同构，几乎是不可能的事。

但是认真想题后可以发现：重点就是化为两个函数对不同取值差的比。

可以发现，如果把公式中的两个取值点尽可能靠近（因为是任取的，所以总是可以），那其实就是导数的变体（分母套了函数，但可以换元思想）。

于是，斜率优化 DP 的很多问题都可以宏观化思考：求下凸包是为了保证斜率永远单增，因为经过一个不增的点是在浪费计数，完全可跳过；求首次相交就是切线，如果是割线的话上下割点的都不如切点。

剩下都是模板套路。


## 周四：分块和莫队

这一天的内容思维都不难。

但是分快写起来非常困难，分割、判段、暴力影响预处理都不好写。

而分块本质是暴力的优化，对这种复杂度的算法优化就注定比原暴力复杂得多，导致思维都放在代码细节上，不好适应。

莫队则十分简洁巧妙，理解原理后代码基本上不会出错，再加上可以无脑套模板，确实不难。

但是树上莫队、回滚莫队这些思维难度变高很多，比较吃力。


## 周五：高斯消元和线性基

感觉这一天的内容在理论上很有趣。

高斯消元解决的是最常见的问题，解题思路又非常符合人的思维，而且边界判断少，写起来非常舒适。

更重要的是不仅其方法可以拓展到环的运算上，更能抽象出逐步解决问题并用固定解决不固定的思想，这在许多搜索问题里有体现。

线性基则理论上十分神奇：异或运算对每一位的独立性恰好把数变成最简单的二元向量，利用去重思想把每一维抽出一个代表，用这个思想就非常好理解。

而线性基又方便辨认，代码少，因此感觉上比较轻松。


## 周六：考试

第一题思路非常简单，但是犯了宏定义低级错误，这种难于调试的 bug 相当消耗时间。

第二、三题也没有花时间思考，导致第二题解法复杂许多，细节处很多错。

第三题是经典的大量特判，这种必须精确考虑数据的题目还是多对拍比较好。

第四题是个人问题：这种题通常都是想通后极其简单，但是我看到数据范围就放弃了，完全没有意识到这是在暗示简单做法，大概与经验不足有关。

第五六题似乎不是很好写，实际考试可能写不出来。

但第七题这种博弈论其实是有套路可循的，虽然写完了却还是漏了两个边界条件。

**主要问题**：比较急躁，没有认真思考解答或 bug ；轻易放弃；追求较难题的部分分而非简单题的全分；时间把握不好；环境因素。
