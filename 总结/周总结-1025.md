## 考试情况

### color

**题意**：每次操作，给节点及子树染上一种颜色，颜色可以叠加。
每次查询一个节点的子树上有多少种不同的颜色。

**解法**：原来 ODT 还真的有实际用途。

子树问题想到 DFN 序。
对于每一种颜色，维护其所覆盖的区间。
形态一定是**多个不交的区间**，其中被包含的不计。

于是就可以每个颜色开 ODT 来解决抹平区间的问题。
每次插入颜色，先检查是否已经被覆盖。
如果没被覆盖，则拍平整个区间，并将区间中原本无该颜色的段在线段树上递增。
> 单次摊平是均摊 $O(m)$，$m$ 为操作次数。

统计答案时，即求 DFN 序上区间和。

### meet

**题意**：给定序列。
已知 $2$ 个指针开始指向的数相同，给出它们向中间跳经过的一系列数，最后在某一个数相遇。
求相遇数在原序列中的可能位置。
保证每个指针中间跳过的数互不相同。

**解法**：水紫，居然是道模拟？

对于每一对起始的数，假设左指针能合法跳到的最左的结束位置为 $x$，右指针能合法跳到的最右的结束位置为 $y$，那么显然 $x$ 与 $y$ 中间所有值为相遇值的位置都是可能的。

我们枚举起始数对时，肯定要尽量靠近端点，以保证覆盖尽可能多的答案。  
> 具体来说：左指针从左出发，每一步都贪心选**最靠左**的合法后继；右指针同理，贪心选**最靠右**的合法后继。
> 这样得到的 $x$ 最靠左、$y$ 最靠右，覆盖的区间最宽。

那么想象一下，两个数对起始位置不同，但是中途某一步跳到的位置相同，那么从这一步往后的剩余序列相同，最终的结束位置也就一样了。
这启示我们预先处理从某个位置出发，跳完剩余序列后到达的 $x$ 和 $y$。

这里利用所跳数两两不同的性质：每个数在序列中只出现一次，所以每个位置有**确定的**后继。于是可以对所有可能在路径上的数去预处理它的最终位置。

> 如果始终选最靠近端点的后继，那么越靠近端点的起始位置，其最终位置只会更靠端点，不会比靠近中点的更居中；因此贪心得到的端点就是最宽松的边界。

枚举时，对每种颜色取它最左和最右的位置，用预处理出的最终位置得到合法区间 $[x,y]$，在差分数组上统计区间覆盖；最终统一做前缀和合并，输出所有被覆盖的位置即为答案。

### community

**题意**：帖子一开始按 $1\sim n$ 排列。
每次操作，将一个帖子移到最开头或末尾。
每次查询，求 $1$ 号帖子的位置。

**解法**：如果求**任意**帖子位置，可能还要考虑数据结构。
只求 $1$ 号帖子？？
乱搞就可以。

最自然的想法显然是 `bitset`，表示一个帖子**在或不在** $1$ 号的前面，同步更新答案变量。
这很直观，但是当将 $1$ 号帖子移动至开头或末尾时，需要设置整个位数组，是 $O(n)$ 的操作。
> 这个担心似乎是多余的：有人就这么 AC 了。

那么可以用奇妙做法：用集合维护有哪些数在 $1$ 号前面 / 后面。
这里是前是后不确定，需要一个标记。

一开始标记为前面，初始化即为空。
每次操作对应 $O(1)$ 的插入 / 删除。
如果要移动 $1$ 号，就清空集合，然后把标记置为操作对应的方位，计算答案时再根据标记判断即可。

> 本人考场上用的是 `unordered_set`，**错误认为**清空和 `vector` 一样是 $O(1)$ 的。
>
> 实际上是 $O(size)$ 的，虽说均摊在每个元素上确实是 $O(1)$，但开销比较大。
> 下面是一个比较让人耳目一新的模拟集合方法。

用数组代替集合。
与位数组的是：每个下标维护版本号。
不移动 $1$ 号帖子时，版本号不变，元素等于版本号对应小标属于集合。
而每次移动 $1$ 号，递增版本号，于是所有旧标记自动失效，也就是集合清空了！
保证了真正 $O(1)$ 的时间复杂度，常数也非常小。

### community（续）

提一提查询任意帖子位置的正解。
因为是没有见过的一种技巧，所以摘录如下。

因为最多 $q$ 次操作，因此在前后各自预留 $q$ 个标号。

每次移到开头，向左递减分配一个未占用的标号，抹去原有标号；移到末尾同理。

查询帖子位置，对应查询帖子标号的前缀占用标号数量，用树状数组维护：$0$ 代表未占用，$1$ 代表已占用；前缀和即是答案。

### merge

**题意**：合并相邻果子，但是每个果子有 $(a_i,b_i)$ 属性值。
合并 $(a_1,b_1)$ 与 $(a_2,b_2)$，释放 $a_1b_2$ 的能量，同时果子变成 $(a_2,b_1)$。
开始前，可以选择一个区间，将区间内果子的 $a$ 和 $b$ 都乘上 $k$。
求最大能量。

**解法**：总感觉是道诈骗题。

注意到，合并左右两个区间时，释放的能量等于**左区间最右果子的 $a$ 乘右区间最左果子的 $b$**。
那么释放的能量一定是某个 $a_ib_{i+1}$。
每对相邻位置恰好贡献一次，总能量于是固定为 $\sum_{i=1}^{n-1}a_ib_{i+1}$。

剩下的就纯 DP 了。
$dp[r]$ 是乘 $k$ 区间右端点为 $r$ 时的最大能量。
右端点移动一格时，原来的 $ka_r\cdot b_{r+1}$ 变为 $ka_r\cdot kb_{r+1}$，原来的 $a_{r+1}\cdot b_{r+2}$ 变为 $ka_{r+1}\cdot b_{r+2}$。方程显而易见：
$$
dp[r+1]=dp[r]+(k^2-k)\cdot a_rb_{r+1}+(k-1)\cdot a_{r+1}b_{r+2}.
$$

最后是统计 $\max_{1\le r\le n}dp[r]$，竟然可以用**滚动变量优化 DP**！

### resource

**题意**：每次操作，给两个节点及它们的子树分配一种新资源。
对于每个节点，输出和它收到过至少一种相同资源的节点总数。

**解法**：联想到 `color`，但是关系不大。

发现能对节点 $u$ 产生影响的都是 $u$ 祖先链上的操作。
不太容易地，想到 DFS，递归子树时把该节点操作计入，那么到 $u$ 时恰好就是**所有影响 $u$ 的操作集合**。

> 总感觉和线段树分治的递归时加入、返回时移除很像，这是不是一种通用的思想？

因为是同时操作 $2$ 棵子树，我们主要维护非当前节点的子树。
当前节点的子树只用保留最浅的那个即可。

于是又变成了经典的统计 DFN 序上，多个区间并的大小问题。
需要使用线段树。
> 这里用线段树是为了动态求并，静态问题可以用差分数组。

套路——线段树维护：
- `cover`：区间被完全覆盖的次数；
- `len`：区间内被覆盖的点数（`cover > 0`）。

那么根节点的 `len` 就是答案，对应普通线段树节点的值。
而 `cover` 扮演的是**懒标记**的角色：
- 增加区间时 `cover` 对应自增；
- `pushup` 时，如果区间的 `cover` 已经大于 $0$，避免重复，答案就是 $r-l+1$；
- 否则答案显然是 `len[lid] + len[rid]`。
> 发现了吗？这就是之前提到的**标记永久化**的典型应用。
> 在这里标记不只是减少操作的惰性求值，其本身就携带影响父亲节点值的信息。
>
> 只不过普通线段树恰好也可以只依赖标记和当前儿子值去更新父亲，因此也是用标记永久化。

时间复杂度 $O((n+m)\log n)$，空间 $O(n+m)$。

### tri

**题意**：一个 $n$ 边形（$n$ 为奇数），每条边被 $a_i$ 个分割点分成 $a_i+1$ 段，边正对的顶点向分割点（不含端点）连 $a_i$ 条边。
求图中有几个三角形。

**解法**：虽说是思维好题，但是放到 NOIP 这个位置还是很神秘。

称多边形自带的边为**旧边**，连出来的边为**新边**。
令 $sum=\sum a_i$。
> 下面的求和符号简记了，可自行观察 $i$ 范围。

考虑三角形的构成：

- $3$ 条新边：贡献 $\binom{sum}3$。
但是如果 $3$ 条边发自同一顶点就不行，于是减去 $\sum\binom{a_i}3$。
- $2$ 条新边 $1$ 条旧边：对于新边分讨：
  - 全从旧边端点发出：那就是 $2$ 个端点各选一条，贡献 $\sum a_ia_{i+1}$；
  - 全从对面顶点射过来：两两构成三角形，贡献 $\sum\binom{a_i}2$；
  - 一条从端点发出，一条从对面射过来：这样一定会相交，产生贡献。
  贡献是 $\sum a_ia_{i+1}a_{i+(n+1)/2}$。

对于 $n>3$，两条旧边是没法贡献三角形的，答案就如上。
对于 $n=3$，两条旧边贡献 $a_i+a_{i+1}$，总共正好贡献 $2sum$。
三条旧边贡献 $1$。

### river
**题意**：构造 $1\sim n$ 排列，若 $i<j$ 且 $a_i<a_j$ 连一条边。
需要使图连通，且有欧拉回路。

**解法**：Nailoong 题。
也就是每个数参与的顺序对有偶数个。

对于 $n$ 为奇数，完全图就满足条件，直接顺序输出。

对于 $n$ 为偶数，每个数的度数都是奇数，那考虑两两消掉一条边。
最简单的方式是交换相邻两个数，比如 $[2,1,4,3]$ 就是一个解。
只要是把一个顺序对变成逆序对就行。

别忘了 $n=2$ 时图不连通，无解。
> 有因为没判这个挂 $10\mathrm{pts}$ 的。\
> 还有不会用 SPJ 挂 $80\mathrm{pts}$ 的/mgx。

### assign
**题意**：给无向图加点权。
有边连接的点点权差 $1$。
孤点必须分配 $0$，如果一个点小于其他所有点，也必须是 $0$。
求方案数。

**解法**：一道不错而令人恼怒的 Ad-hoc。
因为被卡了 1h+，所以写详细一些。

先看一条链：

```
合法：
2 - 1 - 0 - 1 - 2
合法：
1 - 0 - 1 - 0 - 1
非法（最后一个点不为 0）：
0 - 1 - 2 - 1 - 2
```

如果你把高度图画出来就一目了然：

```
合法：
\    /
 \  /   \  /\  /
  \/     \/  \/

非法：
  /\  /
 /  \/
/
```

也就是每个山谷海拔一定为 $0$。
那么相邻山谷间，一定是一个完美单调的峰。
这启发我们记录一个位置是否为山谷，就有唯一的方案。

又因为相邻点高度的奇偶性不同，于是山谷必须全在奇数下标，或全在偶数下标。
例如全选偶的答案是 $2^{\lfloor n/2\rfloor}-1$，减 $1$ 是因为钦定了山谷全在这边，于是必须至少一个山谷。
奇数同理，得到：
$$2^{\lfloor n/2\rfloor}+2^{\lceil n/2\rceil}-2.$$

怎么推广？

这里的奇偶有很明显的二分图性质，把图作出来：

```
* - *
   /
  /
 /
* - *
   /
 ...
```

发现无向图如果有奇环，一个点不能同时满足奇偶性，排除。
剩下的图也恰好是一个二分图。

一定会猜测答案是 $2^{左部点}+2^{右部点}-2$。
是不是呢？模一模，发现<u>&emsp;确实&emsp;</u>。

这是因为钦定左部点中的山谷后，对于一条路径，一定会在左右两部横跳，直到落入下一个山谷。
而这中间都没有山谷，即方案唯一。

对于一个点的所有出边如此，那么左部的所有钦定方案都对应了唯一的加权方法；右部点同理。

这样就把一条链的性质推广出来了。

### Arc211B

**题意**：构造非负整数序列 $S_1,S_2,S_3$，使得两两的最大公共子段长度为给定值 $x\le y\le z$。
在此基础上要求最大数尽可能小。

**解法**：肯定先想全 $0$ 情况。

构造 $|S_1|=x,|S_2|=z,|S_3|=z$ 可以满足 $x=y$ 的情况。
不难发现肯定满足不了 $x\ne y$，因为 $x$ 会出现 $2$ 次。

那么考虑全由 $0$ 和 $1$ 构成。
可以让 $|S_1|$ 是 $y$ 个 $0$，$|S_2|$ 中恰好连续 $x$ 个 $0$，
$|S_3|$ 中恰好连续 $y$ 个 $0$。
这时候 $S_2,S_3$ 个公共长度是 $y$，那再给它们补 $z$ 个 $1$，就把最大公共子段扳成 $z$ 了。
